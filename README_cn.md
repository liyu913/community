## 参与贡献

欢迎完善文档，也欢迎提出项目建设建议。

1. 阅读已有文件，以及相关 Issue 或 Pull Request。
2. 对于较大的改动建议，先提交 Issue，说明问题、建议方案和预期效果。
3. Fork 本仓库，并为改动创建分支。
4. 保持改动范围明确；涉及共同信息时，同步更新中英文 README。
5. 提交 Pull Request，说明修改内容和检查方式。

请勿在贡献内容中包含密码、访问令牌或私人信息。
