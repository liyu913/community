## Contributing

Contributions to the documentation and proposals for the project are welcome.

1. Review the existing files and any relevant issues or pull requests.
2. For a substantial proposal, open an issue to explain the problem, suggested approach, and expected outcome.
3. Fork the repository and create a branch for your change.
4. Make focused changes and keep both README files consistent when updating shared information.
5. Open a pull request describing what changed and how you checked it.

Do not include passwords, access tokens, or private information in contributions.

## Feedback
